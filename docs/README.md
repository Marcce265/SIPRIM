# Documentación SIPRIM

Carpeta para la documentación del proyecto en **PDF** y otros materiales de referencia.

## Cómo usar

1. Copia tus archivos `.pdf` directamente en esta carpeta (`docs/`).
2. Opcional: organiza en subcarpetas si son muchos (por ejemplo `docs/historias/`, `docs/arquitectura/`).
3. Si quieres que aparezcan en el repositorio, haz commit de los PDF junto con el resto del proyecto.
